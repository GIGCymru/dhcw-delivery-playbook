# Contributing to the DHCW Delivery Playbook

This playbook is a living document and improves when people who use it change it.

## How to propose a change

- Small fixes: use the edit button on any page of the published site, which opens
  a pull request against `docs/` in this repository.
- Bigger changes or questions: raise an issue describing what you would change
  and why. Real examples from your team carry the most weight.

All changes are reviewed in the open.

## House style

British English. No em dashes and no exclamation marks. Plain language, short
sentences, natural contractions. Write "DHCW", never "the DHCW". The playbook is
marked Beta until a version is finalised.
